# Password Strength Checker

## Project Overview
The Password Strength Checker is a Python-based cybersecurity project developed as part of the DecodeLabs Industrial Training Program.

The program evaluates password strength and classifies passwords into three categories: Weak, Medium, and Strong.

## Features
- Checks password length.
- Identifies uppercase letters.
- Checks for numeric digits.
- Identifies special characters.
- Displays the password strength.

## Technologies Used
- Python
- getpass module

## Project Objective
To understand basic cybersecurity concepts, password validation, string handling, and conditional statements through practical implementation.
